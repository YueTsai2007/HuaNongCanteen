# 华农食堂 · 微信小程序版（菜单浏览工具）

把 GitHub `YueTsai2007/HuaNongCanteen`（Android 原生客户端）的功能重写为**原生微信小程序**。定位是**菜单浏览工具**：去食堂前先看看各食堂有什么吃的，把想吃的存进清单，到了食堂照着吃——不做在线下单和交易。

## 功能范围

- 首页 8 个食堂入口（荷园/芷园/莘园/西园/稻香园/绿榕园/小吃街/外卖）
- 店铺列表、菜品分类浏览
- **想吃清单**（tab）：浏览时点 ＋ 存入想吃的菜（支持口味备注），到食堂照着找，吃完打勾、一键清掉吃过的
- **菜单数据包内置**：菜单随小程序版本分发，所有用户打开即可浏览；数据仅存本机，无需登录、无需服务器

## 更新菜单流程（主人）

1. 小程序里录入/修改好店铺和菜品；
2. 「我的 → 生成菜单数据包」→ 内容自动复制到剪贴板；
3. 粘贴替换 `data/seed.js` 里的 `shops` / `dishes`（`version` 已自动 +1）；
4. 重新上传发布小程序版本，审核通过后大家即可看到新菜单。

注意：菜品/店铺**图片不随数据包分发**（体积原因），用户端显示占位图。

## 本地开发（无需 AppID）

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）。
2. 「导入项目」→ 选择本 `miniprogram/` 目录 → AppID 选「测试号」。
3. 编译即可预览。

## 发布上线（个人主体 · 免费）

1. 在 mp.weixin.qq.com 注册小程序（个人主体免费），拿到 AppID 并完成**小程序备案**（平台内操作，约 1-3 周）。
2. 把 AppID 填入 `project.config.json` 的 `appid` 字段。
3. 类目建议选「工具-效率」或「生活服务」，介绍写「食堂菜单浏览与想吃清单工具」（不做交易，无需经营资质）。
4. 开发者工具「上传」→ 后台设为体验版 → 真机验收（菜单浏览、存清单）。
5. 提交审核发布。

## 与 Android 端的关系

- 本小程序已改为**纯本地版**（无账号、无云同步）；Android 端的点单/云同步功能不受影响。
- 代码里保留了 `utils/api.js` / `sync.js` / `images.js` 备用：以后若要升级为云同步（微信云开发或自建后端），可直接复用。
- 金额一律整数「分」；清单键规则：`dishId:note`，不同备注分行。
